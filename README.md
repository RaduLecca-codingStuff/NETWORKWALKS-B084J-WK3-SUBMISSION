# NETWORKWALKS-B084J-WK3-SUBMISSION


### Project overview

This the third weekly lab assignment for the Networkwalks' cybersecurity programme. The goal of the project is to perform commonly used password cracking procedures on a set of password-protected PDF files, provided by Networkwalks, in a controlled setting.
Submission consists of the following:
- The password-protected PDF files associated
- Screenshots of the tools used for each method
- Screenshots of the contents of the contents for each PDF file
- Text Files with the passwords extracted through each tool

### Objectives:
- Use hash calculation web services to retrieve the digest of a password protected PDF
- Use John-The-Ripper in order to identify the original plaintext resulting from a hash
- Install the Johnny UI interface to use in conjunction with John-The-Ripper
- Use Networkwalks' online hash calculation, wordlist generator and password cracking tools to retrieve the passwords from a separate list of password-protected PDF files
